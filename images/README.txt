HOW TO REPLACE A MOCK IMAGE
Save your real photo in this folder with the SAME file name as the mock (see FILE-LIST.txt), but with extension .webp, .jpg, .png (any one).
Example: garden-special.svg is the mock -> add garden-special.jpg. No code change needed. Square or 4:3 photos, ~900px wide, under 150 KB work best.
The site tries .webp, .jpg, .jpeg, .png, then the mock .svg.
